# 结论

**这本书是一条拆前提的链条。** 第1–4章在三个前提都成立的理想世界里把问题彻底解决，然后每一部分拆掉其中一个，重新解决一遍。

| 前提 | 现实中做不到 | 谁拆掉它 | 换成什么 |
|---|---|---|---|
| 你知道游戏规则 | 机器人不会告诉你「往右走 20% 会打滑」 | **第5、7章** | 不算，去试，用样本代替计算 |
| 情况少到能列成一张表 | 关节角度连续，情况无穷多 | **第8章** | 会举一反三的神经网络 |
| 先算分数，再挑分高的动作 | 动作连续，无穷多个挑不出最大 | **第9、10章** | 跳过分数，直接学怎么做 |

# 开车类比

**第1–2章**　先有一本操作手册，再想办法给它打分。

**第3章**　什么叫最好的手册？每一条都写了最好的做法。

**第4章**　打分 → 改手册 → 再打分 → 再改，直到改不动。改不动了就是最好的。

**第5、7章**　前面都假设你知道路况规则（下雨路滑多少、刹车距离多远）。现实中不知道，那就开出去试。

**第8章**　路况有无穷多种，手册写不完。换一个会举一反三的东西——神经网络。

**第9、10章**　前面都是「先给每个动作打分，再挑分高的」。可「方向盘转多少度」有无穷多种，打不完分。那就跳过打分，直接练手感。

**手册 = 策略（policy）。一本写着「遇到什么情况、就做什么动作」的册子。**

# 逐章详解

## 第一部分：理想世界里的完整解（1–4章）

### 第1章　认识几个词

- **状态**：你现在在哪。机器人在第3格、关节转到 37 度。
- **动作**：你能做的事。上下左右、踩刹车、转多少度。
- **奖励**：做完一个动作，环境立刻给的分。到目标 +1，撞墙 −1。
- **策略**：一张表，每个状态填一个动作。**这是你最终要找的东西。**
- **回报**：从现在起，往后所有奖励打折加起来。

**为什么打折？** 往后没有尽头，不打折会加到无穷大，两个无穷大没法比。打折之后是个有限的、能比大小的数。

### 第2章　怎么给一本手册打分

打分要算两个数。**状态值 $v_\pi(s)$** 是站在这格、按手册走平均能拿多少，给位置打分；**动作值 $q_\pi(s,a)$** 是站在这格强行先做某个动作、之后按手册走平均能拿多少，给选择打分。

「往后所有奖励」是无穷多项，加不完。

但这个无穷的和能压缩成两项：

> 从现在起能赚的全部 = 下一步立刻到手的 + 打折 × 从下一步起能赚的全部

这叫**自举**：用自己定义自己。

这样一来 $v(s_1)$ 要先知道 $v(s_2)$，$v(s_2)$ 又要先知道 $v(s_1)$，绕成一圈。

把每个 $v$ 看成未知数，这就是 $n$ 个状态、$n$ 个方程的方程组，一起解就行。这组方程叫**贝尔曼方程**。

解法有两条：求逆精确但状态一多就算不动，反复迭代粗糙但扛得住规模。实践中走第二条。

*检验：给任意一本手册算出每格的分数。*

### 第3章　什么叫最好的手册

一本手册每一格都不比另一本差，就说它更好。最好的那本，比所有其他手册都好。

凭什么存在这么一本全能冠军？**因为每一格填什么互不影响。** 第3格填最好的动作，不妨碍第7格也填最好的。既然每格能单独填到最好，「每格都最好」的手册就一定存在。

把「挑最好的动作」写进方程，得到**贝尔曼最优方程**。它比第2章多一个 $\max$，因而是非线性的，第2章的解法全废。

对付非线性方程用**压缩映射定理**：每做一次操作误差都缩水一定比例，反复做下去必然收敛到唯一答案。这定理同时回答三件事：**解存在、解唯一、有算法能找到。** 解只有一个，所以你停在哪儿就只能是那儿，不会卡在局部最优。

*检验：说清楚「最优」是什么、为什么一定存在、为什么不会卡在局部最优。*

### 第4章　怎么把最好的手册找出来

一个循环：

> 打分 → 每格挑分最高的动作 → 分数作废 → 重新打分 → 再挑 → ……

分数会作废，是因为它算的是「照这本手册办事能拿多少」，手册一改就不作数了。

每轮只变好不变差，而手册的组合有限，所以循环必然停下。停下的地方满足贝尔曼最优方程，而它的解唯一，所以那就是最优的。

两种做法的区别只有一个：

| | 中间打分打几轮 |
|---|---|
| **策略迭代** | 打到准为止 |
| **值迭代** | 只打一轮就去改 |

**同一个算法，参数不同。** 打得粗糙没关系，挑动作只要**排序**对，不要精确数值。

*检验：在一个小网格上手算出最优策略。*

## 第二部分：拆掉「知道规则」（5–7章）

前四章每一步都在查地图：这个动作通向哪里、多大概率、给多少奖励。**现实中这张地图不存在**，打分那一步直接做不了。

### 第5章　不知道规则，那就去试

$$\underbrace{\text{按概率加权平均}}_{\text{要地图}} \;\longrightarrow\; \underbrace{\text{跑几趟，把结果平均}}_{\text{只要能试}}$$

你不知道投简历的成功率，但可以真去投一百次，把结果平均。**平均出来的，就是那个算不出来的期望。**

**蒙特卡洛**：走完一整趟，记下总共拿了多少；走很多趟，平均。

代价是必须走完一趟才学得到东西。这趟很长、或者根本没有终点，就卡住了。

### 第6章　随机近似（先跳过）

数据一个个来的时候，怎么一点点更新估计值，而不是攒够一堆再平均。核心是「每次朝目标挪一小步」。

**它是第7章的地基。等看到那个奇怪的更新公式再回来。**

### 第7章　每走一步就学一次

还是第2章那个自举：当前的值 = 这一步奖励 + 打折 × 下一步的值。

走一步就拿到了「这一步的奖励」和「下一步的估计值」，**立刻能更新，不用等终点。**

$$v(s) \leftarrow v(s) + \alpha\big[r + \gamma v(s') - v(s)\big]$$

中括号里是「刚看到的」减「原来估的」，差多少就往那个方向挪一点。**这个差就是「时序差分」这名字的来历。**

| | 蒙特卡洛 | 时序差分 |
|---|---|---|
| 什么时候更新 | 一趟走完 | 每走一步 |
| 参考答案 | 全是真实结果 | 一步真实 + 后面估计 |
| 需要有终点吗 | 需要 | 不需要 |
| 波动 | 大 | 小 |
| 偏差 | 没有 | 有，会慢慢消失 |

**Q-learning 在这一章。** 它跳过状态值直接学动作值。学到 $q$ 就等于学到怎么做决策，学到 $v$ 还差一张地图。

*检验：理解现代 RL 算法的核心更新公式。*

## 第三部分：拆掉「能列成表」（第8章）

### 第8章　手册写不完，换成会举一反三的东西

前七章都假设**每个状态一个格子，能用表格装下**。真实机器人的关节角度是连续的，状态无穷多。

换成神经网络：输入状态，输出这个状态值多少。它不查表，学规律，**没见过的状态也能猜出个大概。**

$$\text{表格：一格一个数，互不相干} \;\longrightarrow\; \text{网络：学规律，能外推}$$

训练目标是让网络的输出接近真值：

$$J(w) = \mathbb{E}\big[(v_\pi(s) - \hat v(s,w))^2\big]$$

**第3章的「每格互不影响」到这里失效了。** 网络的参数是共享的，一套参数管所有状态，调它让某个状态变好，很可能让另一个变差。既然要取舍，「每格都最好」的手册就不存在了，第8、9章必须换一套「最优」的定义。

**DQN 在这一章。深度强化学习从这里开始。**

*检验：明白神经网络在 RL 里只是「一个会举一反三的表格」。*

## 第四部分：拆掉「先算值再选动作」（9–10章）

### 第9章　不打分了，直接学策略

前八章都是先算值、再由值挑动作：

$$a = \arg\max_a q(s,a)$$

**死穴在这一步。** 动作是连续的时候（转多少度、踩多深），有无穷多个，没法一个个试着挑最大的。

**这和第8章不是同一个问题。** 第8章是状态太多装不下，第9章是**动作太多挑不出来**。神经网络解决了前者，解决不了后者：你还是得对无穷多个动作求最大值。

让神经网络直接输出动作，跳过值。

代价是没法当场知道做得好不好，只能走完一整趟看总分，又掉回蒙特卡洛那个坑：**波动极大，训练不稳。**

*检验：说清楚第8章和第9章解决的不是同一件事。*

### 第10章　两条路合起来

**第9章的病，第7章治过。**

- **Actor（演员）** = 策略网络，做动作 → 治好「连续动作没法挑」
- **Critic（评论家）** = 值网络，用 TD 每步当场打分 → 治好「要等一趟走完、波动大」

**像学开车：你自己开（Actor），副驾坐着教练随时点评（Critic）。**

Critic 给的评价，正式写法是**优势函数**：

$$A(s,a) = q(s,a) - v(s)$$

**做这个具体动作，比在这个状态下随大流，好多少。** 就是第2章两个概念相减。

| | 加了什么 | 用在哪 |
|---|---|---|
| **PPO** | 每次别改太猛 | **最广泛**，RLHF、游戏、人形机器人 |
| **SAC** | 奖励保持随机、鼓励探索 | 机器人、连续控制 |

**骨架一样，补丁不同。Critic 的核心公式就是第2章的贝尔曼方程。**

*检验：看懂 PPO 在干什么。*

# 三个反复出现的模式

**一、真实算多少 / 估计顶多少**

| | 一个极端 | 中间 | 另一个极端 |
|---|---|---|---|
| 打分打几轮 | 值迭代（1轮） | 截断策略迭代 | 策略迭代（算到准） |
| 走几步再用估计 | TD（1步） | n 步 TD | 蒙特卡洛（走到底） |

**两个端点各有名字，但它们在同一根轴上。**

**二、自举**

「当前的值 = 这一步的奖励 + 打折 × 下一步的值」。第2章推出来的这个式子，一路用到第10章的 Critic。

**三、折扣率 $\gamma$ 反复救场**

让无穷级数收敛（第2章）、表达「多看重远期」（第2章）、保证矩阵可逆和迭代收敛（第2、3章）、自动避免绕远路（第3章）。**一个参数，四个作用。**
