# 强化学习第 1–4 章：造一个会自己找路的机器人

## 总目标

```
        列1      列2      列3
      ┌────────┬────────┬────────┐
 行1  │   s1   │   s2   │   s3   │
      │ 机器人 │        │        │
      ├────────┼────────┼────────┤
 行2  │   s4   │   s5   │   s6   │
      │        │        │  禁区  │
      ├────────┼────────┼────────┤
 行3  │   s7   │   s8   │   s9   │
      │  禁区  │        │  目标  │
      └────────┴────────┴────────┘

每格五个动作： ↑ → ↓ ← 和原地不动
```

**要造的东西**：一个机器人，从任意格子出发都能走到目标，不绕路、不进禁区、不撞墙。

**唯一的约束**：你不能告诉它路线。你只能在它每做一个动作后给一个数字。它可以在每个格子把五个动作都试一遍，记住各自的反馈，然后自己琢磨怎么拿更多分。

> 答案紧跟在每个问题后面，中间用 `···` 隔开。先自己想，再往下看。

## 第一关 · 让它朝目标走

**当前方案**：撞墙 −1，进禁区 −1，到目标 +1，其他 0。规则是每格选数字最大的动作。

**跑一下**：它确实学会了不撞墙、不进禁区——那两个动作是 −1，明显更差。但它从不朝目标移动，停在 s1 不动。

**惩罚生效了，奖励没生效。**

**问题 1**　同一套反馈，为什么一半管用一半不管用？

*提示：站在 s1，把五个动作的数字都写出来。目标那个 +1 出现在里面吗？*

···

**答案 1**

机器人站在 s1，五个动作的即时反馈：

```
              ↑ −1  撞墙
              │
   −1 ───── [ s1 ] ─────→ 0   到 s2
   撞墙       │  ⟲ 0 原地不动
              ↓ 0   到 s4
```

**目标那个 +1，根本没出现在这张表里。**

它能排除撞墙，是因为撞墙的代价**当场发生、就在眼前这一格**。但从 s1 走到目标最少要 4 步，那个 $+1$ 落在它的视野之外。

剩下的右、下、不动是个三向平局，都是 0。按顺序取第一个就可能永远不动，随机取就是乱走。

**惩罚项恰好都是即时的**（撞墙、进禁区当场兑现），**奖励项是远处的**（要走四步才兑现）。「选即时反馈最大」这条规则只看得见眼前一格，所以只能吸收前者。

**修法**：注意奖励表**一个字都不用改**——书里从第 1 章到第 10 章用的就是这套 −1/−1/+1/0。错的是决策规则。

改成不看单步，而是**让机器人按当前走法一直走下去，把沿途收到的所有数字加起来**。这个总和叫**回报（return）**：

$$
\text{return} =  r_1 + r_2 + r_3 + \cdots
$$

其中 $r_1$ 是第一步得到的数字，$r_2$ 是第二步的，依此类推。（这里用小写，因为是某一次实际跑出来的具体数值；第二关会换成标准的随机变量记号。）**一个动作的好坏，由它开启的那整条路的回报决定，而不是由它当场拿到的那个数字决定。**

拿 s1 的两个候选动作实际算一遍：

```
选「右」：s1 → s2 → s5 → s8 → 目标
          r：  0    0    0    +1        回报 = 0+0+0+1 = 1

选「下」：s1 → s4 → s7 → s8 → 目标
          r：  0   −1     0    +1       回报 = 0−1+0+1 = 0
                    ↑ 踩进禁区
```

**第一步的数字都是 0，分不出高下；回报是 1 和 0，分出来了。** 而且结论跟直觉一致——第二条路踩了禁区，所以更差。

$+1$ 被拉进视野了，$-1$ 也被拉进来了，同一个机制。

**对照原书**（1.6 节，式 (1.1) 与 (1.2)）：书里用的就是这两条轨迹，
$$s_1\xrightarrow{a_2,\ r=0}s_2\xrightarrow{a_3,\ r=0}s_5\xrightarrow{a_3,\ r=0}s_8\xrightarrow{a_2,\ r=1}s_9,
\qquad \text{return}=0+0+0+1=1$$
$$s_1\xrightarrow{a_3,\ r=0}s_4\xrightarrow{a_3,\ r=-1}s_7\xrightarrow{a_2,\ r=0}s_8\xrightarrow{a_2,\ r=1}s_9,
\qquad \text{return}=0-1+0+1=0$$
并指出：回报由**即时奖励**和**未来奖励**两部分组成，即时奖励为负而未来奖励为正是完全可能的，所以决策必须依据回报而非即时奖励，否则会做出短视的选择。

**新麻烦**：如果这条路是无限长的，总和会发散。→ 第二关

## 第二关 · 让分数能比较

**修好第一关后的方案**：不看单步，看整条路的数字总和。

**跑一下**：先说清楚到达目标之后发生什么——**机器人不会消失，任务也不结束**。目标格 $s_9$ 就是个普通格子，动作空间跟别处一样。它到了之后选「原地不动」，下一步还在 $s_9$，于是**每一步都再拿一次** $r_{\text{target}}=+1$。

把走法和它产生的奖励序列画在一起看：

```
   ┌──────┬──────┬──────┐
   │  s1  │  s2  │  s3  │      走法 A（最短，4 步）
   ├──────┼──────┼──────┤        s1 → s2 → s5 → s8 → 目标
   │  s4  │  s5  │ 禁区 │              ①    ②    ③    ④
   ├──────┼──────┼──────┤
   │ 禁区 │  s8  │ 目标 │      走法 B（绕路，6 步）
   └──────┴──────┴──────┘        s1 → s2 → s5 → s4 → s5 → s8 → 目标
                                    ①    ②    ③    ④    ⑤    ⑥
                                              └─ 在 s4、s5 间多来回一次 ─┘

   两种走法产生的奖励序列：

   A：  0,  0,  0,  1,  1,  1,  1,  1, …   总和 = ∞
                   ↑           ↑
              第4步到达    之后每步都再 +1

   B：  0,  0,  0,  0,  0,  1,  1,  1, …   总和 = ∞
                           ↑
                      第6步才到达
```

直觉上第一条明显更好。但两条路的差别只在**开头有限的几项**，后面各自拖着一条一模一样的无限尾巴。尾巴发散，把有限的差异整个淹没了。

**问题 2**　$\infty = \infty$，比不出来。怎么办？你能想出几种修法？

···

**答案 2**

三种修法：

1. 到目标就停 —— 也就是把 $s_9$ 设成**吸收状态**，进去就不再产生奖励。可行，但这样只能处理有终点的任务（episodic task），处理不了永不结束的任务（continuing task，比如让机器人一直保持平衡）。书里选择**不**这么做，而是把两类任务统一成后者。
2. 算平均而不是总和 —— 可行，但数学上麻烦得多
3. **让后面的数字越来越不值钱**

书里选第三种。写成标准记号之前，先把符号约定说清楚——**下面这套记号后面一直用**：

```
   时刻 t          时刻 t+1        时刻 t+2
     │                │               │
    S_t ──A_t──▶  S_{t+1} ──A_{t+1}──▶ S_{t+2} ···
                  R_{t+1} R_{t+2} 在状态S_t     得到奖励R_{t+1} 采取动作A_t    并转移到S_{t+1}
```

| 记号 | 含义 |
|---|---|
| $t$ | 时间步，$t=0,1,2,\dots$。不是"第几个格子"，是"第几步" |
| $S_t$ | 第 $t$ 步所处的状态 |
| $A_t$ | 第 $t$ 步采取的动作 |
| $R_{t+1}$ | 因为 $A_t$ 而得到的奖励 |
| $G_t$ | 从第 $t$ 步往后，把所有奖励折扣累加得到的**回报** |

**奖励的下标是 $t+1$ 而不是 $t$**，因为奖励是动作的后果：动作在 $t$ 发出，后果在下一刻兑现。有些教材写成 $R_t$，含义相同。

**大写表示随机变量**——真跑之前不知道会得到多少。答案 1 里那个 $0+0+0+1=1$ 用小写，因为是某一次实际跑出来的数值。

于是：

$$
G_t \doteq R_{t+1} + \gamma R_{t+2} + \gamma^{2} R_{t+3} + \cdots
= \sum_{k=0}^{\infty} \gamma^{k} R_{t+k+1},
\qquad \gamma \in (0,1)
$$

代回上面那两条路验证一下（取 $t=0$，也就是从 s1 出发）：

$$
G_0^{A} = 0+\gamma\cdot 0+\gamma^{2}\cdot 0+\gamma^{3}\cdot 1+\gamma^{4}\cdot 1+\cdots
= \frac{\gamma^{3}}{1-\gamma} \xrightarrow{\gamma=0.9} 7.29
$$

$$
G_0^{B} = 0+\gamma\cdot 0+\gamma^{2}\cdot 0+\gamma^{3}\cdot 0+\gamma^{4}\cdot 0+\gamma^{5}\cdot 1+\cdots
= \frac{\gamma^{5}}{1-\gamma} \xrightarrow{\gamma=0.9} 5.90
$$

**两个有限的数，A 大于 B。** 原来 $\infty=\infty$ 比不出来的两条路，现在分出高下了，而且跟直觉一致：早到目标更好。

一般地，$1+\gamma+\gamma^{2}+\cdots = \dfrac{1}{1-\gamma}$，级数收敛。$\gamma$ 叫**折扣率**。

**新麻烦**：引进 $\gamma$ 纯粹是为了让级数别发散，一个技术动作。但它带来的后果远超预期。→ 第三、四关

**对照原书**（1.6 节）：书里明确讨论了到达终点之后怎么办，给了两个选项——
一是把终点设成**吸收状态**（absorbing state），例如令 $\mathcal{A}(s_9)=\{a_5\}$ 或 $p(s_9\mid s_9,a_i)=1$，进去就出不来；
二是把终点当**普通状态**，动作空间跟别处一样，可以离开也可以回来。

**本书选第二种**：$\mathcal{A}(s_9)=\{a_1,\dots,a_5\}$。因为每次到达 $s_9$ 都能拿 $+1$，机器人最终会学会一直待在那儿——这时轨迹无限长，就**必须**用折扣回报才不发散。

式 (1.3) 给的例子是：
$$
\text{discounted return} = 0+\gamma 0+\gamma^{2}0+\gamma^{3}1+\gamma^{4}1+\gamma^{5}1+\cdots = \gamma^{3}\frac{1}{1-\gamma}
$$
并指出 $\gamma$ 的两个作用：一是取消了终止条件、允许无限长轨迹，二是可以调节对近期／远期奖励的侧重。

## 第三关 · 别让它绕路

**修好第二关后的方案**：$G_t = \sum_{k\ge 0}\gamma^{k}R_{t+k+1}$，其中 $\gamma\in(0,1)$。

**担心的事**：走冤枉路的那几步，反馈都是 0，一分惩罚都没有。它会不会瞎绕圈？

很多人的直觉修法是：给每一步都加 −1，逼它走快点。

先看个小地图：

```
      ┌────────┬────────┐          直达： s2 ↓ 目标
      │   s1   │   s2   │          绕路： s2 ← s1 ↓ s3 → 目标
      ├────────┼────────┤
      │   s3   │  目标  │
      └────────┴────────┘

```

取 $\gamma=0.9$：

$$
\begin{aligned}
\text{直达} &= 1+\gamma+\gamma^{2}+\cdots = \frac{1}{1-\gamma} = 10\\
\text{绕路} &= 0+\gamma\cdot 0+\gamma^{2}+\gamma^{3}+\cdots = \frac{\gamma^{2}}{1-\gamma} = 8.1
\end{aligned}
$$

**问题 3**　绕路一分惩罚没有，总分却低了。这说明什么？那个「每步加 −1」的修法，还有必要吗？

···

**答案 3**

**第一层**：绕路受到的惩罚不是负数字，是「正数字来得晚」。折扣本身就是时间成本，所以不需要额外加惩罚，$\gamma$ 已经在干这件事了。

**第二层**：那个「每步加 −1」的修法不但没必要，而且**根本不会改变机器人的行为**。

直觉会说：绕路多走两步，多挨两次 −1，当然更亏。**错在轨迹是无限长的。**

到达目标后机器人一直待在那儿，每条路都要走无穷多步。

设原来某条路的奖励序列是 $r_1, r_2, r_3, \dots$，回报是 $G = \sum_{k\ge 0}\gamma^{k}r_{k+1}$。现在每一步都加 $\beta$，新的奖励序列变成 $r_1+\beta,\; r_2+\beta,\; \dots$，新回报是

$$
G' = \sum_{k=0}^{\infty}\gamma^{k}\left(r_{k+1}+\beta\right)
= \underbrace{\sum_{k=0}^{\infty}\gamma^{k}r_{k+1}}_{G}
+ \underbrace{\sum_{k=0}^{\infty}\gamma^{k}\beta}_{\text{多出来的部分}}
$$

多出来那部分把 $\beta$ 提出来，就是个等比级数：

$$
\sum_{k=0}^{\infty}\gamma^{k}\beta
= \beta\left(1+\gamma+\gamma^{2}+\cdots\right)
= \frac{\beta}{1-\gamma}
$$

于是

$$
G' = G + \frac{\beta}{1-\gamma}
$$

**关键在于 $\dfrac{\beta}{1-\gamma}$ 里不含 $r$，也不含路径长度。** 不管你四步到还是六步到，加的都是同一个常数。

那"绕路多挨两次 −1"的直觉错在哪？错在它默认了轨迹是有限的。若真的只走 4 步和 6 步就结束，多加的量分别是 $4\beta$ 和 $6\beta$，确实不同。但轨迹无限长时，两条路都要加无穷多项，而这两个无穷级数**收敛到同一个值**。

拿第二关那两条路验算（$\gamma=0.9$，每步加 $\beta=-1$，即总共加 $\dfrac{-1}{1-0.9}=-10$）：

| | 原回报 | 每步加 −1 之后 |
|---|---|---|
| A（4 步到达） | 7.29 | $7.29-10=-2.71$ |
| B（6 步到达） | 5.90 | $5.90-10=-4.10$ |
| **A − B** | **1.39** | **1.39（没变）** |

两个数都变小了，但**差值一模一样**。机器人挑的是回报最大的那条，所以选择完全不变。你以为在施压，其实只是把整个刻度平移了一下。

这条性质叫**仿射不变性**：$r \to \alpha r + \beta$（$\alpha>0$）不改变最优策略。

**推论**：想改变行为，必须改变**相对结构**，不能改变**整体水平**。

那把禁区的 −1 单独改成 −10 为什么就管用？因为它**只作用在踩过禁区的那些路线上**。没踩禁区的路一分不减，踩了的路每踩一次多扣 9 分。差值被改写了，排名才可能翻转——这就是图 3.4(d) 里机器人开始绕开所有禁区的原因。

一句话：**全体普降是平移，单独调整才是重排。**

**对照原书**（Theorem 3.6，最优策略不变性）：若每个奖励 $r$ 被仿射变换为 $\alpha r+\beta$（$\alpha>0$），则新的最优状态价值是
$$
v' = \alpha v^{*} + \frac{\beta}{1-\gamma}\mathbf{1} \tag{3.8}
$$
由此导出的贪心最优策略与原来完全相同。

证明的关键一步：把 $v'=\alpha v^{*}+c\mathbf{1}$ 代入新的 BOE，利用 $P_\pi\mathbf{1}=\mathbf{1}$ 化简，最后归结为 $\beta\mathbf{1}+c\gamma\mathbf{1}-c\mathbf{1}=0$，取 $c=\beta/(1-\gamma)$ 即成立。

## 第四关 · 调节它的胆量

**现在的状况**：$\gamma$ 是你手里唯一的旋钮。

**要搞清楚的**：拧这个旋钮，机器人的性格会怎么变？

**问题 4**　$\gamma$ 从 0.9 调到 0.5 会怎样？调到 0 呢？

*提示：从 s1 到目标要 4 步。先算 $\gamma$ 不同时，「4 步之后那个 +1」在当下还值多少。*

···

**答案 4**

「4 步之后那个 +1」折算到当下还值 $\gamma^{4}$：

| $\gamma$ | $\gamma^{4}$ | 含义 |
|---|---|---|
| 0.9 | 0.656 | 远处的目标依然很有分量 |
| 0.5 | 0.063 | 已经淡到几乎看不见 |
| 0 | 0 | 完全消失 |

- **$\gamma=0.9$**：**敢**穿过禁区抄近路。吃一个 −1，但早到目标赚回来了。
- **$\gamma=0.5$**：不敢冒险了，宁可绕远路避开所有禁区。
- **$\gamma=0$**：**完全到不了目标**——退化成第一关那个只看即时反馈的机器人。

所以 $\gamma$ 不是个超参数，它是「这个智能体有多长的时间视野」的数学定义。

## 第五关 · 状态（state）

**当前的做法**：「在哪个格子」就是**状态** $s$，全体构成**状态空间** $\mathcal{S}=\{s_1,\dots,s_9\}$。

**问题 5**　让它玩牌，或者预测股价，这种状态定义还够用吗？不够的话怎么补救？

···

**答案 5**

**判据**：一个状态定义够用，指的是**它把决策所需的信息全装进去了，你不需要再回头看历史**。

这个判据的正式名称是**马尔可夫性（Markov property）**：

$$
p(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots, s_0, a_0) = p(s_{t+1} \mid s_t, a_t)
$$

左边把全部历史都列上，右边只留当前的 $s_t, a_t$。两边相等，就说明历史里没有额外信息——**知道现在，就等于知道全部**。

拿三个例子检验：

| | 状态定义 | 满足吗 | 为什么 |
|---|---|---|---|
| 围棋 | 当前盘面 | ✓ | 盘面一样，后续最优下法就一样，跟落子顺序无关 |
| 股票 | 今天的价格 | ✗ | 同一个价格，可能在上涨趋势中也可能在下跌趋势中 |
| 打牌 | 我的手牌 | ✗ | 看不到对手手牌，同一个状态下胜率完全不同 |

**不满足怎么办？先看一个观察**：上面三行里，变的是"状态定义"这一列，不是环境本身。围棋、股票、打牌都是客观存在的，满不满足取决于**你把什么装进了状态**。

所以马尔可夫性不是世界的属性，是**你怎么定义状态**的属性。修的办法就是重新定义状态。

**但两类失效的修法不一样：**

**股票能修。** 缺的历史你观测得到，打包进去就行：$s=(\text{今日价格})$ 改成 $s=(\text{过去 5 天价格})$。趋势信息进了状态，马尔可夫性恢复。代价是状态空间膨胀——原来一维，现在五维。

**打牌修不了。** 对手的手牌你从头到尾就没看见过，翻遍自己的历史也变不出来。这叫**部分可观测**（POMDP），不是状态定义粗糙的问题，需要另一套方法，本书不涉及。

**为什么这么在意马尔可夫性？** 因为**没有它就没有贝尔曼方程**——第七关的推导里有一步直接用了它。整栋楼建在这块砖上。

**对照原书**（1.7 节，式 (1.4)）：

$$
\begin{aligned}
p(s_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\dots,s_0,a_0) &= p(s_{t+1}\mid s_t,a_t)\\
p(r_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\dots,s_0,a_0) &= p(r_{t+1}\mid s_t,a_t)
\end{aligned}
$$

注意奖励也满足这条，不只是状态转移。

**第一阶段完成。** 你现在手里有五样东西，加上一条假设。这一整套叫**马尔可夫决策过程**（MDP，Markov Decision Process）。

名字是三个词拼的，倒着读最清楚：

- **过程**（Process）——不是一次性的选择，是随时间一步步演化的序列 $s_0, a_0, r_1, s_1, a_1, r_2, \dots$
- **决策**（Decision）——每一步你有得选。去掉这个词就只剩被动演化，没有决策可言
- **马尔可夫**（Markov）——演化满足第五关那条假设：未来只取决于现在

五样东西按书里的分法归成三组：

| 组 | 内容 | 记号 | 谁说了算 |
|---|---|---|---|
| **集合** | 状态空间 | $\mathcal{S}$ | 环境 |
| | 动作空间 | $\mathcal{A}(s)$ | 环境 |
| | 奖励集合 | $\mathcal{R}(s,a)$ | **你**（设计者） |
| **模型** | 状态转移概率 | $p(s'\mid s,a)$ | 环境 |
| | 奖励概率 | $p(r\mid s,a)$ | **你**（设计者） |
| **策略** | 什么状态做什么 | $\pi(a\mid s)$ | **机器人**（要学的东西） |

模型（model / dynamics）就是 $p(s'\mid s,a)$ 和 $p(r\mid s,a)$ 这两个概率的合称。**第四部分的三个算法都要求它已知，第 5 章之后才不要求**——这个区别后面会反复提到。

三方各管一摊：环境定死了规则，你通过奖励表达意图，机器人只能改策略。**接下来的全部工作，都是在优化 $\pi$ 这一个变量。**

**对照原书**（1.7 节）：书里还点了一句：**策略一旦固定，MDP 就退化成马尔可夫过程（MP）**——不再有"选择"，只剩下状态之间按固定概率转移。图 1.7 把格子世界画成了这样一张状态转移图。

这解释了为什么第二关到第九关能把 $\pi$ 当成已知：策略固定后没有选择可言，问题从"决策"退化成"演化"，就好算了。

## 第六关 · 环境随机时怎么评价

**新情况**：格子里刮风。机器人想往右走，有 50% 概率被吹到别处。

**跑一下**：从同一个格子出发跑 100 次，得到 100 条不同的路、100 个不同的分数。

**问题 6**　那么「从这个格子出发能得多少分」到底是多少？

···

**答案 6**

不存在「那个」分数，只存在一个分布。要拿它比较策略，只能取**期望**：

$$
v_\pi(s) \doteq \mathbb{E}\left[G_t \mid S_t = s\right]
$$

逐个符号读：$G_t$ 是第二关定义的折扣回报（随机变量）；竖线 $\mid$ 读作"在……条件下"；$S_t=s$ 是条件，即"第 $t$ 步正好处在状态 $s$"；$\mathbb{E}[\cdot]$ 取期望。合起来就是：**从 $s$ 出发、按 $\pi$ 行动，把所有可能轨迹的回报按各自概率加权平均。** 下标 $\pi$ 提醒你这个值依赖策略，换个策略就变。

这叫**状态价值**。三条性质：依赖 $s$，依赖 $\pi$，**不依赖 $t$**（策略定了它就是个固定的数，跟你什么时候到那儿无关）。

**对照原书**（2.3 节）：先定义轨迹上的折扣回报
$$
G_t \doteq R_{t+1}+\gamma R_{t+2}+\gamma^{2}R_{t+3}+\cdots
$$
再取条件期望 $v_\pi(s)\doteq \mathbb{E}[G_t\mid S_t=s]$，称为 **state-value function**。**新麻烦**：定义出来了，但怎么算？→ 第七关

---

## 第七关 · 把分数真的算出来

**要达成**：给定一个策略，算出每个格子的分数。

**卡点**：四个格子首尾相接，策略让机器人绕圈走。

```
      ┌────────┬────────┐          s1 ──r₁──→ s2
      │   s1  →│   s2   │           ↑           │
      │   ↑    │   ↓    │          r₄          r₂
      ├────────┼────────┤           │           ↓
      │   s4  ←│   s3   │          s4 ←──r₃─── s3
      └────────┴────────┘
```

$$
\begin{aligned}
v_1 &= r_1 + \gamma v_2\\
v_2 &= r_2 + \gamma v_3\\
v_3 &= r_3 + \gamma v_4\\
v_4 &= r_4 + \gamma v_1
\end{aligned}
$$

$v_1$ 要先知道 $v_2$，$v_2$ 要先知道 $v_3$，$v_3$ 要先知道 $v_4$，$v_4$ 又要先知道 $v_1$。

**问题 7**　这不是循环论证吗？为什么它居然能算？

···

**答案 7**

想象高速上的路牌，每块写着「距北京 XXX 公里」。每块牌的数字都可以由**下一块**牌推出来。单看一块牌你觉得它依赖别人、没法确定；把整条路上的牌**联立起来**，所有数字唯一确定。

困惑来自你**站错了观察层级**：

- 单个方程的层级：循环论证
- 方程组的层级：一个良定义的线性系统

$$
v_\pi = r_\pi + \gamma P_\pi v_\pi
\quad\Longrightarrow\quad
v_\pi = (I-\gamma P_\pi)^{-1} r_\pi
$$

（$r_\pi$ 和 $P_\pi$ 都带下标 $\pi$，因为它们依赖当前策略。）

这个「用自己定义自己」的手法叫 **bootstrapping**，是后面所有算法的核心机制。

**对照原书**（2.6 节，式 (2.8)–(2.10)）：先把逐状态的方程整理成
$$
v_\pi(s) = r_\pi(s) + \gamma\sum_{s'\in\mathcal{S}} p_\pi(s'\mid s)\, v_\pi(s')
$$
其中
$$r_\pi(s)\doteq\sum_{a\in\mathcal{A}}\pi(a\mid s)\sum_{r\in\mathcal{R}}p(r\mid s,a)\,r,
\qquad p_\pi(s'\mid s)\doteq\sum_{a\in\mathcal{A}}\pi(a\mid s)\,p(s'\mid s,a)$$
再令 $[P_\pi]_{ij}=p_\pi(s_j\mid s_i)$，得到式 (2.10)：
$$
v_\pi = r_\pi + \gamma P_\pi v_\pi
$$
$P_\pi$ 有两条性质，后面反复要用：**非负** $P_\pi\ge 0$，**行和为一** $P_\pi \mathbf{1}=\mathbf{1}$。

**新麻烦**：这个解要求矩阵可逆。→ 第八关

---

## 第八关 · 保证一定算得出来

**上一关的结论**：$v_\pi = (I-\gamma P_\pi)^{-1} r_\pi$。

**卡点**：这个式子要求 $I-\gamma P_\pi$ 可逆。万一不可逆，整套方法当场作废。

**问题 8**　凭什么保证它一定可逆？

*提示：$P_\pi$ 每行非负且行和为 1（因为是概率），另外 $\gamma<1$。*

···

**答案 8**

用 Gershgorin 圆盘定理：矩阵的每个特征值都落在某个圆盘里。$I-\gamma P_\pi$ 的第 $i$ 个圆盘

$$
\text{圆心} = [I-\gamma P_\pi]_{ii} = 1-\gamma p_\pi(s_i\mid s_i),
\qquad
\text{半径} = \sum_{j\neq i}\bigl|[I-\gamma P_\pi]_{ij}\bigr| = \sum_{j\neq i}\gamma\, p_\pi(s_j\mid s_i)
$$

因为行和为 1，$\sum_{j\neq i}p_\pi(s_j\mid s_i) = 1-p_\pi(s_i\mid s_i)$，于是

$$
\sum_{j\neq i}\gamma\,p_\pi(s_j\mid s_i)
= \gamma\bigl(1-p_\pi(s_i\mid s_i)\bigr)
< 1-\gamma p_\pi(s_i\mid s_i)
$$

**半径严格小于圆心到原点的距离**。所以没有一个圆盘包含原点，没有零特征值，矩阵可逆。

上面那个严格不等号，唯一的来源是 $\gamma<1$。

留意一下：$\gamma$ 引进来是为了让级数收敛（第二关），现在它又在保证矩阵可逆。第十三关它还会第三次出现，保证迭代收敛。**它是整套理论的地基，不是一个调参数。**

**对照原书**（2.7.1 节）：除了可逆，还给了 $(I-\gamma P_\pi)^{-1}$ 的两条性质——
$$
(I-\gamma P_\pi)^{-1} = I+\gamma P_\pi+\gamma^{2}P_\pi^{2}+\cdots  \ge  I  \ge  0
$$
以及：若 $r\ge 0$ 则 $(I-\gamma P_\pi)^{-1}r\ge r\ge 0$；若 $r_1\ge r_2$ 则 $(I-\gamma P_\pi)^{-1}r_1\ge(I-\gamma P_\pi)^{-1}r_2$。

**实际不用求逆**（2.7.2 节，式 (2.11)）。闭式解只用于理论分析，真算的时候用迭代：
$$
v_{k+1} = r_\pi + \gamma P_\pi v_k,\qquad k=0,1,2,\dots
$$
收敛性（式 (2.12)）：令误差 $\delta_k = v_k-v_\pi$，可得 $\delta_{k+1}=\gamma P_\pi\delta_k$，于是
$$
\delta_{k+1}=\gamma^{k+1}P_\pi^{k+1}\delta_0 \to 0
$$
因为 $P_\pi^{k}$ 每个元素都不超过 1，而 $\gamma^{k}\to 0$。**这个迭代式就是第十六关里策略迭代的内层循环。**

## 第九关 · 让它据此行动

**当前状况**：你已经能算出每个格子的分数了。把这张表交给机器人。

**问题 9**　它站在某个格子里，看着这张表，知道该往哪走吗？

···

**答案 9**

不知道。

$v_\pi(s)$ 告诉它「我现在这个处境值 8 分」，但没告诉它「往右走会怎样」——那得先知道往右会到哪个格子、那个格子值多少，也就是需要模型；如果环境随机还得对所有落点求期望。

所以要定义一个直接可用的量：

$$
q_\pi(s,a) \doteq \mathbb{E}\left[G_t \mid S_t = s,\ A_t = a\right]
$$

跟 $v_\pi(s)$ 只差一个条件：多规定了第 $t$ 步采取的动作是 $a$。之后仍然按 $\pi$ 走。

**动作价值**。它直接回答「在这个处境下做这件事值多少」，机器人挑最大的 a 就行。

两者的换算：

$$
v_\pi(s) = \sum_{a\in\mathcal{A}} \pi(a\mid s)\, q_\pi(s,a)
$$

$$
q_\pi(s,a) = \sum_{r\in\mathcal{R}} p(r\mid s,a)\, r
 +  \gamma \sum_{s'\in\mathcal{S}} p(s'\mid s,a)\, v_\pi(s')
$$

**对照原书**（2.8 节）：上面两式分别是式 (2.13) 和式 (2.14)，书里称它们是"一枚硬币的两面"——(2.13) 从动作价值得到状态价值，(2.14) 从状态价值得到动作价值。

另外 2.8.2 节还给出了用动作价值表达的贝尔曼方程（式 (2.15)）：
$$
q_\pi = \tilde{r} + \gamma P\Pi q_\pi
$$
它的特点是 $\tilde r$ 和 $P$ 都与策略无关、只由模型决定，策略全部装在 $\Pi$ 里。

## 附加关 · 一个反直觉的地方

**观察到的现象**：机器人当前的策略，在 s1 从来不往上走。

**问题 10**　`q(s₁, 向上)` 是多少？是 0 吗？还是根本没定义？以及，你为什么要关心一个它从来不做的动作？

···

**答案 10**

**不是 0，也不是没定义。** 它是一个良定义的数：

$$
q_\pi(s_1, a_{\uparrow}) = -1 + \gamma\, v_\pi(s_1)
$$

意思是「如果我破例往上走一次（撞墙 −1，弹回 s₁），然后**继续按老策略走**，能拿多少」。反事实问题，完全可以算。

**为什么关心**：因为当前策略可能就是烂的。它不选这个动作，不代表这个动作不好——可能恰恰是它错过了最好的选项。

一个只评估自己现有行为的系统，无法自我改进。这是**探索（exploration）**的起点。

---

**第二阶段完成。** 把第六到第九关的东西合起来写，就是**贝尔曼方程**：

$$
v_\pi(s) = \sum_{a\in\mathcal{A}} \pi(a\mid s)
\left[
\underbrace{\sum_{r\in\mathcal{R}} p(r\mid s,a)\, r}_{\text{即时奖励均值}}
+ \gamma \underbrace{\sum_{s'\in\mathcal{S}} p(s'\mid s,a)\, v_\pi(s')}_{\text{未来奖励均值}}
\right],
\quad \forall s\in\mathcal{S}
$$

三层加权平均分别对应：策略的随机性、奖励的随机性、转移的随机性。矩阵形式 $v_\pi = r_\pi + \gamma P_\pi v_\pi$。解它的过程叫**策略评估**。

# 第三部分 · 什么叫「最好」

**新的目标**：到现在为止你只会**评价**一个给定的策略。但你要的是**最好的**那个策略。

问题是——「最好」这个词，你还没定义过。

---

## 第十一关 · 定义「最好」

**最自然的定义**：「$\pi_1$ 比 $\pi_2$ 好」 $\iff$ 对**每一个**状态 $s$ 都有 $v_{\pi_1}(s) \ge v_{\pi_2}(s)$。

**问题 11**　如果 $\pi_1$ 在左上角更好、$\pi_2$ 在右下角更好，谁更好？

以及一个更要命的问题：凭什么保证存在一个打败所有人的策略？

···

**答案 11**

**第一问**：没法比。这个定义给出的是**偏序**，不是全序。两个策略完全可能互不可比。

**第二问才要命**：不保证。定义一个概念不等于这个概念存在——你可以定义「最大的自然数」。

所以第 3 章必须依次回答四个问题，一个都不能省：存在性、唯一性、随机性、算法。

定义 → 存在性 → 唯一性 → 算法，这是数学的标准流程。

**对照原书**（Definition 3.1）：策略 $\pi^{*}$ 是**最优的**，如果对所有 $s\in\mathcal{S}$ 和任意其他策略 $\pi$ 都有
$$
v_{\pi^{*}}(s)\ \ge\ v_\pi(s)
$$
$\pi^{*}$ 的状态价值称为**最优状态价值** $v^{*}$。

书里紧接着列出必须回答的四个问题：存在性、唯一性、随机性、算法。

---

## 第十二关 · 写出最优策略满足的方程

**方程本身不难写**：最优时每个格子的分数都取到能取的最大值。

$$
v(s) = \max_{\pi(s)\in\Pi(s)} \sum_{a\in\mathcal{A}} \pi(a\mid s)\, q(s,a),
\qquad \forall s\in\mathcal{S}
$$

**对照原书**（式 (3.1)，贝尔曼最优方程 BOE 的逐元素形式）：
$$
v(s)=\max_{\pi(s)\in\Pi(s)}\sum_{a\in\mathcal{A}}\pi(a\mid s)\left(\sum_{r\in\mathcal{R}}p(r\mid s,a)\,r+\gamma\sum_{s'\in\mathcal{S}}p(s'\mid s,a)\,v(s')\right)
$$
括号里那一整块就记作 $q(s,a)$。矩阵形式是式 (3.2)：
$$
v=\max_{\pi\in\Pi}\left(r_\pi+\gamma P_\pi v\right)\doteq f(v) \tag{3.3}
$$
**卡点**：里面有两个未知数（$v$ 和 $\pi$），但只有一个方程。

**问题 12**　怎么解？

*先拿这个小例子热身：`x = max_y (2x − 1 − y²)`，你会怎么下手？*

···

**答案 12**

**热身题**：先解内层的 $y$。不管 $x$ 取何值，$\max_{y}(2x-1-y^{2}) = 2x-1$，在 $y=0$ 处取到。$y$ 定了，方程塌缩成 $x = 2x-1$，得 $x=1$。

思路是：找出那个「在其他量给定时可以被独立最优化」的变量，先把它解掉。

回到原方程。因为 $\sum_{a}\pi(a\mid s)=1$ 且 $\pi(a\mid s)\ge 0$：

$$
\sum_{a\in\mathcal{A}} \pi(a\mid s)\, q(s,a)
 \le  \sum_{a\in\mathcal{A}} \pi(a\mid s) \max_{a'\in\mathcal{A}} q(s,a')
 =  \max_{a'\in\mathcal{A}} q(s,a')
$$

（注意里层的 $\max$ 必须换一个哑变量 $a'$，否则和外层求和的 $a$ 撞了。）

等号在 $\pi$ 把概率 1 全押给 $a^{*}=\arg\max_{a} q(s,a)$ 时取到：

$$
\pi^{*}(a\mid s)=
\begin{cases}
1, & a = a^{*}\\
0, & a \neq a^{*}
\end{cases}
$$

**所以最优策略是贪心的。**

**对照原书**（Theorem 3.5，贪心最优策略，式 (3.7)）：对任意 $s\in\mathcal{S}$，确定性贪心策略
$$
\pi^{*}(a\mid s)=\begin{cases}1,& a=a^{*}(s)\\ 0,& a\neq a^{*}(s)\end{cases}
$$
是 BOE 的一个最优策略，其中 $a^{*}(s)=\arg\max_a q^{*}(s,a)$，
$$
q^{*}(s,a)\doteq\sum_{r\in\mathcal{R}}p(r\mid s,a)\,r+\gamma\sum_{s'\in\mathcal{S}}p(s'\mid s,a)\,v^{*}(s')
$$
这跟「三个标的收益 3%、5%、8%，分配权重使总收益最大」是同一个问题：线性目标加上权重和为 1，最优解必在顶点。

$\pi$ 解掉后，方程变成 $v = f(v)$。

---

## 第十三关 · 解出来

**上一关的结论**：$\pi$ 可以先解掉，方程塌缩成 $v=f(v)$，其中 $f(v)\doteq\max_{\pi\in\Pi}\left(r_\pi + \gamma P_\pi v\right)$。

**卡点**：它是非线性的（有 max），第八关那套求逆用不了了。

最朴素的想法：随便猜个 v₀，然后反复算 `v₁ = f(v₀)`、`v₂ = f(v₁)`……

**问题 13**　凭什么相信它会收敛？凭什么相信结果不依赖你最初瞎猜的那个 v₀？

···

**答案 13**

把计算器调成弧度制，输入任意一个数，不停按 `cos`。输入 0、100、−7 都一样，最后都收敛到 0.739085…，即 `x = cos x` 的解。初值完全不影响。

因为 cos 是**压缩映射**：它把任意两点之间的距离缩小。

$$
\|f(x_1) - f(x_2)\| \le \gamma \|x_1 - x_2\|,
\qquad \gamma\in(0,1)
$$

**压缩映射定理**一次给三样东西：不动点存在、唯一、且从任意起点迭代都指数级收敛。

$\gamma$ 相当于复印机的缩小率，越接近 1 收敛越慢——越长期主义的问题算起来越慢。

剩下的工作是证明 $f(v)$ 确实是压缩映射（Theorem 3.2）。注意这里用的是**无穷范数**（向量各分量绝对值的最大值），换个范数结论不一定成立：

$$
\|f(v_1)-f(v_2)\|_{\infty} \le \gamma \|v_1-v_2\|_{\infty}
$$

核心那一步很朴素：$P_\pi$ 每行非负且行和为 1，所以对任意一行 $p_i^{\mathsf{T}}$，

$$
\bigl|p_i^{\mathsf{T}}(v_1-v_2)\bigr| \le p_i^{\mathsf{T}}|v_1-v_2| \le \|v_1-v_2\|_{\infty}
$$

加权平均不会超过最大值。

**对照原书**：

**Theorem 3.1（压缩映射定理）** 对形如 $x=f(x)$ 的方程，若 $f$ 是压缩映射，则
存在唯一不动点 $x^{*}$，且迭代 $x_{k+1}=f(x_k)$ 对任意初值 $x_0$ 都收敛到 $x^{*}$，收敛速度是指数级的。

**Theorem 3.2（$f(v)$ 的压缩性）** 对任意 $v_1,v_2\in\mathbb{R}^{|\mathcal{S}|}$，
$$
\|f(v_1)-f(v_2)\|_{\infty}\le\gamma\|f\text{ 的自变量之差}\|_{\infty}=\gamma\|v_1-v_2\|_{\infty}
$$
其中 $\|\cdot\|_\infty$ 是最大范数。证明的骨架是先夹出
$$
\gamma P_{\pi_2^{*}}(v_1-v_2)\ \le\ f(v_1)-f(v_2)\ \le\ \gamma P_{\pi_1^{*}}(v_1-v_2)
$$
再逐分量取绝对值的最大值。

## 第十四关 · 结算

**问题 14**　压缩映射定理插进来后，第十一关提的那几个问题（存在性、唯一性、随机性、算法）同时被回答了。自己对一遍。

···

**答案 14**

| 问题 | 答案 |
|---|---|
| $v^{*}$ 存在吗 | 存在 |
| $v^{*}$ 唯一吗 | **唯一** |
| 怎么求 | $v_{k+1}=f(v_k)$，即值迭代 |
| $\pi^{*}$ 最优吗 | 是（Theorem 3.4） |
| $\pi^{*}$ 唯一吗 | **不唯一**（图 3.3 反例） |
| $\pi^{*}$ 随机还是确定 | 都可以，但必存在确定性贪心最优策略 |

注意那个不对称：**价值唯一，策略不唯一**——两条不同的路可能一样短。

**对照原书**：

**Theorem 3.3（存在性、唯一性、算法）** BOE $v=f(v)=\max_{\pi\in\Pi}(r_\pi+\gamma P_\pi v)$ 总有唯一解 $v^{*}$，可由
$$
v_{k+1}=f(v_k)=\max_{\pi\in\Pi}\left(r_\pi+\gamma P_\pi v_k\right),\qquad k=0,1,2,\dots
$$
迭代求出，对任意初值 $v_0$ 指数级收敛。**这个迭代就是第 4 章的值迭代算法。**

**Theorem 3.4（最优性）** 该解 $v^{*}$ 就是最优状态价值，$\pi^{*}$ 就是最优策略：对任意 $\pi$ 有 $v^{*}=v_{\pi^{*}}\ge v_\pi$。
证明思路是反复自我压缩：
$$
v^{*}-v_\pi\ \ge\ \gamma P_\pi(v^{*}-v_\pi)\ \ge\ \cdots\ \ge\ \gamma^{n}P_\pi^{n}(v^{*}-v_\pi)\ \to\ 0
$$

# 第四部分 · 真的把它算出来

**新的目标**：前面证明了最优解存在、唯一、可迭代求出。现在要落地成能跑的算法。

## 第十五关 · 两条技术路线

- **A**：不管当前策略好不好，每轮把 $v$ 往前推一步，顺手更新策略（就是第十三关那个迭代）
- **B**：先把当前策略**彻底评估清楚**（解出精确的 $v_{\pi_k}$），再基于它贪心一次得到新策略，然后再评估、再贪心

**问题 15**　哪个每轮更贵？哪个需要的轮数更少？以及：B 里「贪心一次」凭什么保证新策略不会变差？

···

**答案 15**

A 是**值迭代**，B 是**策略迭代**。

B 每轮贵得多，因为它的「彻底评估」内部还嵌套了第七关那个迭代（迭代套迭代）。但 B 需要的轮数少。

**策略改进引理**：若 $\pi_{k+1}=\arg\max_{\pi}\left(r_\pi+\gamma P_\pi v_{\pi_k}\right)$，则 $v_{\pi_{k+1}} \ge v_{\pi_k}$——这里 $\ge$ 是**逐分量比较**，即在每一个状态上都不比原来差。加上 $v_\pi \le v^{*}$ 有上界：

$$
v_{\pi_0} \le v_{\pi_1} \le v_{\pi_2} \le \cdots \le v^{*}
$$

单调递增加有上界，必收敛。

一般优化问题里每步贪心会卡在局部最优，这里为什么不会？因为 $q$ 值里已经**编码了完整的未来**。贪心的是动作选择，不贪心的是评估视野。

**对照原书 · 值迭代**（Algorithm 4.1）每轮两步，逐元素形式为
$$
q_k(s,a)=\sum_{r}p(r\mid s,a)\,r+\gamma\sum_{s'}p(s'\mid s,a)\,v_k(s')
$$
$$\text{策略更新：}\ \pi_{k+1}(a\mid s)=\begin{cases}1,&a=a_k^{*}(s)\\0,&\text{否则}\end{cases}
\qquad a_k^{*}(s)=\arg\max_a q_k(s,a) \tag{4.2}$$
$$
\text{值更新：}\ v_{k+1}(s)=\max_a q_k(s,a)
$$
整条链路是 $ v_k(s)\to q_k(s,a)\to \pi_{k+1}(s)\to v_{k+1}(s)$。

**书里的写法 · 策略迭代**（Algorithm 4.2）每轮也是两步：
$$
\text{策略评估（PE）：解出}\ v_{\pi_k}=r_{\pi_k}+\gamma P_{\pi_k}v_{\pi_k} \tag{4.3}
$$
$$
\text{策略改进（PI）：}\ \pi_{k+1}=\arg\max_{\pi}\left(r_\pi+\gamma P_\pi v_{\pi_k}\right)
$$
其中 (4.3) 用内层迭代求解（式 (4.4)）：
$$
v^{(j+1)}_{\pi_k}=r_{\pi_k}+\gamma P_{\pi_k}v^{(j)}_{\pi_k},\qquad j=0,1,2,\dots
$$
**Lemma 4.1（策略改进）** 若 $\pi_{k+1}=\arg\max_\pi(r_\pi+\gamma P_\pi v_{\pi_k})$，则 $v_{\pi_{k+1}}\ge v_{\pi_k}$。

**Theorem 4.1（策略迭代收敛）** 状态价值序列 $\{v_{\pi_k}\}_{k=0}^{\infty}$ 收敛到 $v^{*}$，因而 $\{\pi_k\}$ 收敛到一个最优策略。
证明的办法很巧：另造一个值迭代序列 $\{v_k\}$ 做夹逼，用归纳法证 $v_k\le v_{\pi_k}\le v^{*}$，而 $v_k\to v^{*}$。**顺带说明了策略迭代比值迭代收敛快。**

---

## 第十六关 · 让 B 能真的跑起来

**卡点**：B 里那个「彻底评估」理论上要迭代无穷次才能得到精确的 $v_{\pi_k}$。实际做不到。

**问题 16**　如果只迭代 10 次就停，用一个不精确的值去做策略改进，算法还能收敛到最优吗？

···

**答案 16**

**能。** 这叫**截断策略迭代**。

让 A 和 B 从同一个初值出发，前三步完全一样，第四步分岔：

在第 $k$ 轮的策略评估里，内层迭代 $v^{(j+1)}_{\pi_k} = r_{\pi_k} + \gamma P_{\pi_k} v^{(j)}_{\pi_k}$ 跑到第几步就停，决定了你在用哪个算法：

```
v⁽⁰⁾ = v_{k-1} │
  ├─ v⁽¹⁾            ← 值迭代在这里停
  ├─ v⁽²⁾
  │   ⋮
  ├─ v⁽ʲ⁾            ← 截断策略迭代在这里停
  │   ⋮
  └─ v⁽∞⁾ = v_{π_k} ← 策略迭代跑到这里
```

| 算法 | 内层迭代次数 |
|---|---|
| 值迭代 | **1** |
| 截断策略迭代 | 有限的 j |
| 策略迭代 | **∞** |

**三者是同一个算法的三个取值。**

实践建议（书里 Q&A）：跑几次，别太多。多跑几次显著加速，跑太多边际收益递减。

**对照原书**（4.3 节）：两个算法的步骤并排写出来是
$$
\text{策略迭代：}\ \pi_0\xrightarrow{PE}v_{\pi_0}\xrightarrow{PI}\pi_1\xrightarrow{PE}v_{\pi_1}\xrightarrow{PI}\pi_2\to\cdots
$$
$$
\text{值迭代：}\ v_0\xrightarrow{PU}\pi_1'\xrightarrow{VU}v_1\xrightarrow{PU}\pi_2'\xrightarrow{VU}v_2\to\cdots
$$
令 $v_0=v_{\pi_0}$，前三步两者结果相同；第四步值迭代做的是**一次**计算 $v_1=r_{\pi_1}+\gamma P_{\pi_1}v_0$，而策略迭代要解 $v_{\pi_1}=r_{\pi_1}+\gamma P_{\pi_1}v_{\pi_1}$，需要**无穷次**内层迭代。

**Algorithm 4.3（截断策略迭代）** 就是把内层循环的次数设为有限的 $j_{\text{truncate}}$，初值取 $v_k^{(0)}=v_{k-1}$。

**Proposition 4.1（值改进）** 若内层初值取 $v^{(0)}_{\pi_k}=v_{\pi_{k-1}}$，则对所有 $j$ 有
$$
v^{(j+1)}_{\pi_k}\ \ge\ v^{(j)}_{\pi_k}
$$
即内层每多跑一次，估值只增不减。

书里也诚实地指出一个缺口：这条命题要求 $v^{(0)}_{\pi_k}=v_{\pi_{k-1}}$，但实践中拿得到的只有 $v_{k-1}$，不是精确的 $v_{\pi_{k-1}}$。

## 第十七关 · 别把过程量当真

**场景**：值迭代跑到第 5 轮，你手里有一个 $v_5$。你想拿它做点分析。

**问题 17**　这个 $v_5$ 是某个策略的状态价值吗？策略迭代跑到第 5 轮的 $v_{\pi_5}$ 呢？截断策略迭代的呢？

···

**答案 17**

- **值迭代的 $v_k$：不是。** 它不满足任何策略的贝尔曼方程（一般地 $v_k \neq r_{\pi_k}+\gamma P_{\pi_k}v_k$），只是算法的中间产物，因此 $q_k$ 也不是真的动作价值。只在收敛时才变成 $v^{*}$。
- **策略迭代的 $v_{\pi_k}$：是。** 它是解贝尔曼方程解出来的。
- **截断策略迭代的：不是。** 只跑了有限次，是近似。

像在雾里爬山，手里的高度计读数在过程中不准，只有到山顶才准。

**对照原书**（4.1.1 节与 4.5 节 Q&A）：值迭代中的 $v_k$ 一般既不满足 $v_k=r_{\pi_{k+1}}+\gamma P_{\pi_{k+1}}v_k$，也不满足 $v_k=r_{\pi_k}+\gamma P_{\pi_k}v_k$，所以它不是任何策略的状态价值，$q_k$ 相应地也不是动作价值。

三个算法的共同结构——每轮"更新值 + 更新策略"——书里称为**广义策略迭代（generalized policy iteration）**，第 5 章以后的算法基本都落在这个框架里。

---

# 第五部分 · 通往后面几章的问题

到这里机器人已经能找到最优走法了。但有个前提你可能没注意到。

**问题 18**　第四部分所有算法都要求你知道 $p(s'\mid s,a)$ 和 $p(r\mid s,a)$——也就是**你必须先知道世界的规则**。可开头说好的约束是你不能告诉它路线。

不知道规则时，你还剩下什么？

···

**答案 18**

只剩**数据**。

书里那句话是整个第 5 章的起点：没有模型就必须有数据，没有数据就必须有模型，两个都没有就什么也做不了。

这里的「数据」指机器人跟环境交互时产生的**经验样本** $(s,a,r,s')$——它真的走了一步，看见了实际拿到的奖励和实际落到的格子。

模型是「规则的完整描述」，数据是「规则的若干次抽样」。有了足够多的抽样，你可以绕开规则本身。

---

**问题 19**　承上。B 路线里唯一用到模型的地方，是「评估当前策略的 q 值」这一步。

如果不能用模型算 q，但可以让机器人**真的去跑很多次**，你会怎么估 q？

···

**答案 19**

用**采样平均**代替求期望。

$q_\pi(s,a)$ 的定义是 $\mathbb{E}[G_t \mid S_t=s, A_t=a]$。既然是期望，那就：

1. 从 $(s,a)$ 出发，之后按 $\pi$ 行动，跑完一条轨迹
2. 算出这条轨迹的回报 $G^{(i)}$
3. 重复 n 次，取平均

大数定律保证 $n$ 够大时 $\frac{1}{n}\sum_{i=1}^{n} G^{(i)} \to q_\pi(s,a)$。

把策略迭代里那个需要模型的策略评估步换成这个，就是 **MC Basic**。第 4 章的其他零件（贪心改进、收敛性）一个都不用动。

**代价有两条，第 5 章的后半本都在处理它们**：

- 每个 $(s,a)$ 都要跑很多条完整轨迹才能估准，极其低效
- 必须保证每个 $(s,a)$ 都被访问到。如果策略是确定性的，它压根不会去试某些动作，那些 q 值就永远估不出来——这正好接上第十关那个反直觉的地方（探索）

---

**问题 20**　第三关说仿射变换不改变最优策略。反过来：哪些奖励修改**会**改变最优策略？有没有办法既加速学习，又保证最优策略不变？

···

**答案 20**

**会改变最优策略的**：任何改变奖励**相对结构**的修改。比如把 `r_forbidden` 从 −1 单独改成 −10，其他不动——机器人立刻不敢穿禁区抄近路了（书里图 3.4d）。

**既加速又不改变最优策略的办法：有。** 叫 potential-based reward shaping，书里 [9] 那条引用指向的就是它。

做法是给每个状态定一个「势能」`Φ(s)`（比如「离目标的负距离」），然后在原奖励上加一项：

$$
F(s,a,s') = \gamma\,\Phi(s') - \Phi(s)
$$

**为什么它不改变最优策略**：沿任何一条闭合回路把这一项累加起来，结果恒为零。所以机器人没法靠绕圈刷分。它只是把「远处的 +1」提前泄露一部分到沿途，让学习信号不再那么稀疏——正好治第一关那个病。

这超出了第 1–4 章的范围，知道有这么个东西就行。

---

**问题 21**　到现在状态和动作都是一张表，9×5=45 个数存得下。如果一个状态是一张 256×256 的图片呢？表格法在哪一步先崩？

···

**答案 21**

**先崩的不是存储，是访问。**

256×256 的灰度图，状态数是 256 的 65536 次方。存不下是显然的，但就算你有无穷大的硬盘，还有个更根本的问题：

**表格法要求每个状态被访问很多次才能估准它的价值。** 而这些状态里，绝大多数在整个训练过程中一次都不会出现。表格里绝大部分格子永远是空的。

更要命的是：**表格法没有泛化能力。** 两张只差一个像素的图片，在表格里是两个毫不相干的条目。机器人在第一张图上学到的东西，对第二张图一点用都没有。

所以要换一种表示：用一个参数化函数 `v(s, w)` 去近似价值，参数量远小于状态数。相近的状态自然得到相近的估值。

这是第 8 章的起点，也是神经网络进入强化学习的位置。
