# 结论

**这本书是一条拆前提的链条。** 第1–4章先在三个前提都成立的理想世界里解决问题，之后每部分拆掉一个，重解一遍。

| 前提 | 现实中做不到 | 谁拆掉它 | 换成什么 |
|---|---|---|---|
| 知道游戏规则 | 机器人不会告诉你「往右走 20% 会打滑」 | **5、7章** | 不算，去试 |
| 情况少到能列成一张表 | 关节角度连续，情况无穷多 | **8章** | 会举一反三的神经网络 |

# 开车类比

**手册 = 策略（policy）。一本写着「遇到什么情况、就做什么动作」的册子。**

**第1–2章**　先有一本操作手册，再给它打分。

**第3章**　什么叫最好的手册？每一条都写了最好的做法。

**第4章**　给每条做法打分 → 每条都改成分最高的那个 → 手册一改，旧分数不作数，重新打分 → 再改 → …… → 改不动了，就是最好的。

**第5、7章**　前面假设你知道路况规则（下雨路滑多少、刹车多远停住）。现实中不知道，就开出去试。

**第8章**　路况无穷多种，手册写不完。换个会举一反三的东西：神经网络。

**第9、10章**　前面是「给每个动作打分，挑分高的」。可方向盘转多少度有无穷种，打不完分。跳过打分，直接练手感。

# 逐章详解

## 第一部分：理想世界里的完整解（1–4章）

### 第1章　认识几个词

- **状态**：你在哪。机器人在第3格、关节转到 37 度。
- **动作**：你能做的事。上下左右、踩刹车、转多少度。
- **奖励**：做完动作环境立刻给的分。到目标 +1，撞墙 −1。
- **策略**：一张表，每个状态填一个动作。**这是你最终要找的东西。**
- **回报**：从现在起，往后所有奖励打折加起来。

**为什么打折？** 奖励可以一直拿下去，不打折就是无穷大，两个无穷大没法比。打折后是个有限的数，能比大小。

### 第2章　怎么给一本手册打分

打分要算两个数：

- **状态值**——碰上这种情况，照手册办，平均能拿多少。**给处境打分。**
- **动作值**——碰上这种情况，这次不按手册、改做某个动作，之后再照手册办，平均能拿多少。**给做法打分。**

「往后所有奖励」是无穷多项，加不完。

但这个无穷的和能压缩成两项：

> 从现在起能赚的全部 = 下一步立刻到手的 + 打折 × 从下一步起能赚的全部

这叫**自举**：用自己定义自己。

可这样一来，要知道现在这一步值多少，得先知道下一步值多少；而下一步值多少，又要看再下一步。手册上每一条都这样，互相指来指去，一条都算不出来。

这不是死循环。手册上有几条，就有几个未知数、几个式子，一起解就行，中学的方程组。这组式子叫**贝尔曼方程**。

有两种解法。一是把这组式子直接解出来，答案精确，但手册一长，计算量就大到算不完。二是先随便猜一组分数，再照式子反复修正，答案只是接近，但每轮的计算量不随手册变长而暴涨。实践中用第二种。

### 第3章　什么叫最好的手册

第2章能给手册的每条做法打分了，那就能比手册：**两本手册逐条对分数，一本每条都不比另一本低，就算它更好。** 最好的那本，要比所有手册都好。

这样一本手册是存在的，理由是**每条写什么互不影响**。「遇到红灯怎么办」那条写成最好的，不会妨碍「爆胎怎么办」那条也写成最好的。既然每条都能各自写到最好，把它们凑在一起，就是那本每条都最好的手册。

把「每条都挑最好的」写进第2章那组式子，就是**贝尔曼最优方程**。多了一个「挑最大」的动作，式子的性质变了：第2章那种一次性解出来的办法用不上了，只剩下「先猜一组分数，再反复修正」这一条路。

那怎么知道反复修正一定能修到正确答案上？靠**压缩映射定理**。它说的是：只要每修正一次，你和正确答案的差距都会缩小一定比例，那么反复修正下去，差距必然趋近于零。这一个定理同时回答三件事：**答案存在、答案唯一、反复修正就能找到它。**

其中「唯一」这条保证了一件事：这组式子只有一个答案，所以不管你从哪组分数开始算，反复算下去得到的都是同一个结果，不会算出两套不同的手册。

### 第4章　怎么把最好的手册找出来

> 先给现在这本手册的每条做法打分 → 每条都改成分最高的那个做法 → 手册变了，旧分数不作数，照新手册重新打分 → 再改 → …… → 某一轮改完发现每条都没动，停

每轮只会变好不会变差，而手册的写法只有有限种，所以必然会转到不动。停下的地方满足贝尔曼最优方程，而那个方程的答案唯一，所以这就是最好的手册。

打分这一步本身也是一轮轮逼近的，算得越久越准。算多久就去改手册，是唯一的分歧：

| | 打分算几轮 |
|---|---|
| **策略迭代** | 算到准为止 |
| **值迭代** | 只算一轮就去改 |

**同一个算法，参数不同。** 算得糙没关系，改手册只看哪个做法分高，不看分数具体是多少。

## 第二部分：拆掉「知道规则」（5–7章）

前四章每一步都在查地图：这个动作通向哪里、多大概率、给多少奖励。**现实中这张地图不存在**，打分那一步直接做不了。

### 第5章　不知道规则，那就去试

| | 怎么打分 | 需要什么 |
|---|---|---|
| **前四章** | 按概率加权平均 | 一张地图 |
| **第5章起** | 跑几趟，把结果平均 | 能试就行 |

你不知道投简历的成功率，但可以真投一百次，把结果平均。**平均出来的就是那个算不出来的期望。**

**蒙特卡洛**：走完一整趟，记下总共拿了多少；走很多趟，平均。

代价是必须走完一趟才能学到东西。这趟要是很长，学得就慢；要是压根没有终点（比如一直运行的机械臂），就一个数据也拿不到。

### 第6章　随机近似（先跳过）

第5章的做法是攒够一百趟再求平均。但数据是一趟一趟来的，能不能每来一个就更新一次，不用等攒齐？这一章给出办法：每来一个新数据，就把当前的估计朝它挪一小步。

第7章的更新公式就是这么来的。等你看到那个式子觉得奇怪，再回来读这一章。

### 第7章　每走一步就学一次

还是第2章那个自举：当前的值 = 这一步奖励 + 打折 × 下一步的值。

走一步就拿到了「这步的奖励」和「下一步的估计值」，**立刻能更新，不用等终点。**

$$v(s) \leftarrow v(s) + \alpha\big[r + \gamma v(s') - v(s)\big]$$

中括号里是「刚看到的」减「原来估的」，这个差就是「时序差分」的来历。前面那个 $\alpha$ 是**步长**，控制每次挪多少：取 0.1 就是把差距的十分之一补上，不会因为一次运气好就把估计值改得面目全非。

| | 蒙特卡洛 | 时序差分 |
|---|---|---|
| 什么时候更新 | 一趟走完 | 每走一步 |
| 参考答案 | 全是真实结果 | 一步真实 + 后面估计 |
| 需要有终点吗 | 需要 | 不需要 |
| 波动 | 大 | 小 |
| 偏差 | 没有 | 有，会慢慢消失 |

**Q-learning 在这一章。** 它跳过状态值 $v$，直接学动作值 $q$。学到 $q$ 就等于学到怎么决策；只学到 $v$，还得有地图才知道该走哪步。

## 第三部分：拆掉「能列成表」（第8章）

### 第8章　手册写不完，换成会举一反三的东西

前七章都假设**每个状态一个格子，表格装得下**。真实机器人的关节角度连续，状态无穷多。

换成神经网络：输入一个状态，输出它值多少。表格里每一格的数字是各存各的，查不到就没有；神经网络学的是「什么样的状态值钱」这个规律，所以没见过的状态它也能给出一个大致的数。

训练目标是让网络的输出接近真值：

$$J(w) = \mathbb{E}\big[(v_\pi(s) - \hat v(s,w))^2\big]$$

**DQN 在这一章。深度强化学习从这里开始。**

顺带一提，第3章那个「每条互不影响」到这儿失效了：一套参数管所有状态，调它让这个状态变好，很可能让那个变差。既然要取舍，「每条都最好」的手册就不存在，后面几章得换一套「最优」的说法。

## 第四部分：拆掉「先算值再选动作」（9–10章）

第8章解决了状态太多，但问题还剩一半：**动作也可能太多。**

前八章选动作靠的都是这一步，把当前状态下每个动作的分都算出来，挑最高的：

$$a = \arg\max_a q(s,a)$$

动作是「上下左右」四个，挑得出来。可机械臂的动作是「肘关节转 37.2 度」，**有无穷多个，没法一个个比过去。** 神经网络在这儿帮不上忙，它解决的是状态太多，不是动作太多。

### 第9章　不打分了，直接学策略

既然挑不出来，那就别挑了：**让神经网络直接输出该做什么动作，跳过打分这一步。**

代价是当场没有反馈，只能走完一趟看总分。这就退回了第5章蒙特卡洛的老问题：一趟的总分受一路上几十次运气叠加影响，忽高忽低，拿它去调网络参数，训练很不稳。

### 第10章　两条路合起来

第9章的毛病是「要等一趟走完才知道好坏」，而第7章正好解决了这个。

- **Actor（演员）** = 策略网络。它直接输出动作，不需要把所有动作比一遍，所以动作连续也不怕。
- **Critic（评论家）** = 值网络。它用第7章那套办法每走一步就给个评价，不用等一趟走完。

**像学开车：你自己开（Actor），副驾坐着教练随时点评（Critic）。**

Critic 的评价正式写作**优势函数**：

$$A(s,a) = q(s,a) - v(s)$$

**做这个动作，比在这个状态下随大流好多少。** 就是第2章两个概念相减。

| | 加了什么 | 用在哪 |
|---|---|---|
| **PPO** | 每次别改太猛 | **最广泛**，RLHF、游戏、人形机器人 |
| **SAC** | 奖励保持随机、鼓励探索 | 机器人、连续控制 |

这三个算法的 Actor 和 Critic 是同一套，区别只在 Actor 每轮允许改多少、要不要逼它保持尝试。Critic 用的还是第2章那个贝尔曼方程。

# 三个反复出现的模式

**一、有多少用真实数据，有多少靠估计值顶上**

| | 一个极端 | 中间 | 另一个极端 |
|---|---|---|---|
| 打分打几轮 | 值迭代（1轮） | 截断策略迭代 | 策略迭代（算到准） |
| 走几步再用估计 | TD（1步） | n 步 TD | 蒙特卡洛（走到底） |

**二、自举**

「当前的值 = 这一步的奖励 + 打折 × 下一步的值」。第2章推出来的这个式子，一路用到第10章的 Critic。

**三、折扣率 $\gamma$ 反复救场**

让无穷级数收敛（第2章）、表达「多看重远期」（第2章）、保证矩阵可逆和迭代收敛（第2、3章）、自动避免绕远路（第3章）。同一个 $\gamma$，四个地方都靠它。
